Claude app (claude.ai, desktop, phone)

  1. In Claude, open Settings → Connectors.
  2. Tap Add custom connector, name it Illume Studio and paste the URL above.
  3. Tap Connect, sign in with this account and press Allow.
  4. In a chat, ask: “Make a 9:16 video for my client … in Illume Studio.”

ChatGPT

  1. In ChatGPT, open Settings → Apps & Connectors and turn on Developer mode (under Advanced) if it asks.
  2. Create a new connector, name it Illume Studio, paste the same URL and choose OAuth.
  3. Sign in with this account and press Allow. Then pick Illume Studio in a chat.
